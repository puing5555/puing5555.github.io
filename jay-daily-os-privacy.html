JAY Daily OS 개인정보 처리방침

시행일 및 최종 업데이트: 2026년 10월 9일

JAY Daily OS는 개인 생산성 앱입니다. 현재는 사전에 지정된 Google 계정으로만 로그인할 수 있습니다. 이 방침은 앱을 사용할 때 처리되는 정보와 그 이용 방법을 설명합니다.

1. 처리하는 정보

  • 계정 정보: Google 로그인을 통해 확인되는 이메일 주소와 계정 식별자.
  • 사용자가 입력하거나 저장하는 내용: 할 일, 목표, 메모, 문서, 일기, 코칭 및 세션 기록, 설정, 업로드한 이미지 등 사용한 기능에 따라 앱에 저장한 내용.
  • 오프라인 저장 정보: 연결이 끊겼을 때 복원과 재전송을 위해 브라우저의 IndexedDB에 저장되는 앱 데이터. 로그인 세션은 브라우저 sessionStorage에 보관됩니다.
  • Google 캘린더 정보: 캘린더 연결을 승인하면 일정의 제목·시간 등 표시와 사용자가 요청한 일정 생성 또는 삭제를 위해 Google Calendar API를 사용합니다. Google의 동의 범위는 모든 캘린더 일정의 보기 및 수정 권한을 요청합니다. 현재 앱 기능은 기본(primary) 캘린더의 일정을 브라우저에서 조회하고, 사용자가 요청한 경우 해당 캘린더에 일정을 생성하거나 삭제합니다.
  • AI 요청 정보: AI 기능을 사용할 때 사용자가 보낸 메시지와 해당 기능이 요청에 포함한 관련 문맥. 웹 검색 기능을 켠 요청에는 검색 질의도 포함될 수 있습니다.
  • 기술 정보: 앱 제공업체가 요청을 처리하면서 기록할 수 있는 접속 시각, 요청 경로, 브라우저 및 네트워크 정보 등 기본적인 운영 정보.

2. 이용 목적과 저장 위치

  • 지정된 계정의 로그인 확인과 앱 데이터 동기화, 오프라인 복원 및 변경 이력 보관.
  • 사용자가 선택한 경우 Google 캘린더 일정을 표시하거나 생성·삭제.
  • 사용자가 AI 기능을 호출한 경우 요청에 대한 답변 제공.

앱의 계정·작업 데이터와 복구용 변경 이력은 Supabase에 저장됩니다. 웹 앱과 서버 기능은 Vercel에서 제공됩니다. 오프라인 대기 데이터는 사용 중인 브라우저의 IndexedDB에 보관됩니다. Google Calendar 재연결에 필요한 refresh token은 서버에 보관하며 브라우저에 내려주지 않습니다. Calendar access token은 앱 실행 중 메모리에서 사용합니다.

현재 구현에서 Google 캘린더 일정은 브라우저에서 직접 Google API로 조회·변경하며, 앱 데이터 동기화나 AI 요청에 자동 포함하지 않습니다.

3. 제3자 서비스

  • Google: 로그인과 사용자가 승인한 Google Calendar 기능.
  • Supabase: 인증과 앱 데이터 저장·동기화.
  • Vercel: 웹사이트와 서버 기능 호스팅.
  • Anthropic: 사용자가 AI 기능에 입력한 내용과 관련 문맥을 처리해 답변 생성. 웹 검색을 사용하면 해당 요청의 검색 질의도 처리될 수 있습니다.
  • 전달·표시 서비스: jsDelivr와 Google Fonts는 앱 라이브러리·글꼴 제공에 사용됩니다. 사용자가 포함된 영상을 재생하면 YouTube 임베드가 로드될 수 있습니다.

각 제공업체는 해당 서비스 요청을 처리할 때 자체 개인정보 처리방침에 따라 정보를 처리할 수 있습니다. 앱은 사용자의 데이터를 판매하지 않습니다.

4. 보관 기간과 삭제 요청

앱 데이터는 앱 제공과 복구에 필요한 기간 동안 저장됩니다. 데이터 변경·충돌 복구 이력도 Supabase에 보관될 수 있습니다. 사용자는 아래 이메일로 본인 데이터의 열람·수정·삭제를 요청할 수 있습니다. 요청을 확인한 뒤 운영 데이터와 복구 이력에 가능한 범위에서 반영합니다. 브라우저에 남은 오프라인 사본은 해당 사이트의 브라우저 저장공간을 삭제하면 지울 수 있습니다.

Google Calendar 접근을 중지하려면 Google 계정의 타사 앱 액세스 관리에서 JAY Daily OS의 권한을 철회할 수 있습니다.

5. 보안

앱은 HTTPS 연결, 지정 계정 확인, 사용자별 데이터 접근 제한을 사용합니다. 다만 인터넷 전송이나 저장 방식이 모든 위험으로부터 완전히 안전하다고 보장할 수는 없습니다. 로그인 정보나 민감한 정보를 다른 사람과 공유하지 마세요.
